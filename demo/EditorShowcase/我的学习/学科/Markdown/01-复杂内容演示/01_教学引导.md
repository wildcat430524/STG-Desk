## 01 · Java：把数据处理写得清晰

这个完整示例使用 **Java 17+**，同时包含 **record、枚举、泛型、Stream、归约、排序和异步执行**。注释、字符串、类型和关键字各有区别，正文仍保持安静。

```java
import java.math.BigDecimal;
import java.util.List;
import java.util.Map;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.Executors;
import java.util.stream.Collectors;

public final class StreamLab {
    enum Status { PAID, REFUNDED, CANCELLED }

    record Order(long id, String customer, BigDecimal amount, Status status) {
        Order {
            if (amount.signum() < 0) {
                throw new IllegalArgumentException("金额不能小于 0");
            }
        }
    }

    record CustomerTotal(String customer, BigDecimal total) {}

    // 只统计已支付订单，再按客户聚合金额。
    static List<CustomerTotal> summarize(List<Order> orders) {
        Map<String, BigDecimal> totals = orders.stream()
            .filter(order -> order.status() == Status.PAID)
            .collect(Collectors.groupingBy(
                Order::customer,
                Collectors.reducing(
                    BigDecimal.ZERO, Order::amount, BigDecimal::add
                )
            ));

        return totals.entrySet().stream()
            .map(entry -> new CustomerTotal(entry.getKey(), entry.getValue()))
            .sorted((left, right) -> right.total().compareTo(left.total()))
            .toList();
    }

    public static void main(String[] args) {
        List<Order> orders = List.of(
            new Order(101, "林同学", new BigDecimal("129.90"), Status.PAID),
            new Order(102, "陈同学", new BigDecimal("89.00"), Status.PAID),
            new Order(103, "林同学", new BigDecimal("59.50"), Status.PAID),
            new Order(104, "周同学", new BigDecimal("199.00"), Status.REFUNDED)
        );

        var executor = Executors.newFixedThreadPool(2);
        try {
            CompletableFuture.supplyAsync(() -> summarize(orders), executor)
                .thenAccept(results -> results.forEach(result ->
                    System.out.printf("%s → %s 元%n",
                        result.customer(), result.total())
                ))
                .join();
        } finally {
            executor.shutdown(); // 无论成功还是失败，都释放线程池。
        }
    }
}
```

### 读代码时，可以留意这些位置

- `record Order(...)` 把数据结构放在一起。
- `filter → groupingBy → reducing` 表达整个处理过程。
- `CompletableFuture` 把计算和结果展示连接起来。
- 代码里即使有 `$price` 或 `<String, BigDecimal>`，也不会变成公式或 HTML。

## 02 · 数学：从一个公式，到一段推导

公式可以出现在句子里：对模型 $\hat y=wx+b$，误差是 $\hat y-y$；代码中的 `learning_rate=0.01` 对应步长 $\eta=0.01$。

### 损失与梯度

$$
\begin{aligned}
L(w,b) &= \frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2 \\
\frac{\partial L}{\partial w} &= \frac{2}{n}\sum_{i=1}^{n}x_i(wx_i+b-y_i) \\
\frac{\partial L}{\partial b} &= \frac{2}{n}\sum_{i=1}^{n}(wx_i+b-y_i)
\end{aligned}
$$

> 更新方向由梯度给出。步长控制每次移动多少；先观察误差变化，再调整参数。

### 矩阵、向量与正规方程

$$
\mathbf X=
\begin{bmatrix}
1 & 1 \\
2 & 1 \\
3 & 1 \\
4 & 1
\end{bmatrix},\qquad
\boldsymbol\theta=
\begin{bmatrix}w\\b\end{bmatrix},\qquad
\mathbf y=
\begin{bmatrix}5\\8\\11\\14\end{bmatrix}
$$

当 $\mathbf X^T\mathbf X$ 可逆时：

$$
\boldsymbol\theta^{\ast}=(\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y
$$

### 再试两种不同形状

$$
\int_{0}^{\infty}e^{-x^2}\,dx=\frac{\sqrt\pi}{2},\qquad
\sum_{k=0}^{n}\binom nk a^{n-k}b^k=(a+b)^n
$$

双击任意公式可以修改源式；底部「公式」可以插入新的行内公式或独立公式块。

## 03 · Python：带类型、数据类和迭代的计算

下面的代码只用标准库。目标数据来自 $y=3x+2$，每轮迭代都计算梯度并更新参数。

```python
from dataclasses import dataclass
from math import isfinite
from typing import Iterable


@dataclass(frozen=True)
class Sample:
    x: float
    y: float


def fit_line(
    samples: Iterable[Sample],
    *,
    learning_rate: float = 0.01,
    epochs: int = 2_000,
) -> tuple[float, float, float]:
    data = tuple(samples)
    if not data:
        raise ValueError("至少需要一个样本")

    w, b = 0.0, 0.0
    for epoch in range(epochs):
        residuals = [w * item.x + b - item.y for item in data]
        grad_w = 2 * sum(item.x * error for item, error in zip(data, residuals)) / len(data)
        grad_b = 2 * sum(residuals) / len(data)
        w -= learning_rate * grad_w
        b -= learning_rate * grad_b
        if not (isfinite(w) and isfinite(b)):
            raise ArithmeticError("参数发散，请减小学习率")

    loss = sum((w * item.x + b - item.y) ** 2 for item in data) / len(data)
    return w, b, loss


if __name__ == "__main__":
    training_set = [Sample(x, 3 * x + 2) for x in range(1, 6)]
    weight, bias, loss = fit_line(training_set)
    print(f"w={weight:.4f}, b={bias:.4f}, loss={loss:.6f}")
```

## 04 · TypeScript：泛型、重试与取消

让结果类型明确，让失败也有名字。以下是一个支持退避重试与中止信号的异步包装器。

```typescript
type Result<T> =
  | { ok: true; value: T; attempts: number }
  | { ok: false; error: Error; attempts: number };

interface RetryOptions {
  attempts?: number;
  delayMs?: number;
  signal?: AbortSignal;
}

async function withRetry<T>(
  task: () => Promise<T>,
  { attempts = 3, delayMs = 150, signal }: RetryOptions = {},
): Promise<Result<T>> {
  if (!Number.isInteger(attempts) || attempts < 1) {
    throw new RangeError("attempts 必须是正整数");
  }

  for (let attempt = 1; attempt <= attempts; attempt++) {
    try {
      signal?.throwIfAborted();
      const value = await task();
      signal?.throwIfAborted();
      return { ok: true, value, attempts: attempt };
    } catch (cause) {
      const error = cause instanceof Error ? cause : new Error(String(cause));
      if (signal?.aborted || attempt === attempts) {
        return { ok: false, error, attempts: attempt };
      }
      await new Promise<void>(resolve => {
        setTimeout(resolve, delayMs * 2 ** (attempt - 1));
      });
    }
  }
  throw new Error("不可达分支");
}
```

取消会在任务和退避等待结束后检查；包装器不会强行停止一个已经开始的任务。

## 05 · SQL：窗口查询与分组统计

```sql
WITH paid_orders AS (
    SELECT customer_id, amount, created_at
    FROM orders
    WHERE status = 'PAID'
      AND created_at >= DATE '2026-01-01'
), customer_totals AS (
    SELECT customer_id,
           COUNT(*) AS order_count,
           SUM(amount) AS total_amount,
           AVG(amount) AS average_amount
    FROM paid_orders
    GROUP BY customer_id
)
SELECT customer_id,
       order_count,
       total_amount,
       ROUND(average_amount, 2) AS average_amount,
       DENSE_RANK() OVER (ORDER BY total_amount DESC) AS customer_rank
FROM customer_totals
WHERE order_count >= 2
ORDER BY customer_rank, customer_id;
```
