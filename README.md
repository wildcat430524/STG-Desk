# STG Desk

专门适配 **StepsToGreat** 的 Windows 本地 Markdown 阅读、编辑与答题工作台。当前版本为 **0.3.3**。

## 下载和打开软件

从 [GitHub Releases](https://github.com/wildcat430524/STG-Desk/releases/latest) 下载 `STG-Desk-0.3.3-Windows.exe`，双击运行。源码构建输出在 `release/`，目录版需保留整个 `win-unpacked` 目录。

1. 点击“导入学习文件夹”，或把文件夹从资源管理器拖到窗口。
2. 选择自己的 StepsToGreat 学习工作区。目录会直接读取，不复制学习资料。
3. 软件会恢复上次工作区，并从学习档案找到当前课。顶部只列当前需要的教学引导、学生回答、学习档案、规则、课程路线和被引用资料；“选择课程”只列已发布课程。
4. 打开 `01_教学引导.md` 后，右侧自动关联同目录的 `01_学生回答.md`。
5. 填写当前轮答案，点击“保存本轮作答”。原答追加到对应问题下，保留历史答案与评估；随后可在 DSH 中发送准备好的评估请求。
6. 普通文档编辑后点击“保存”或按 `Ctrl+S`。`Ctrl+O` 导入文件夹。右上角“打开 DSH”可显示当前对话，面板顶部可切换真正独立的小窗。
7. 作答区提供“本轮作答 / 作答记录 / 完整文档”：可查看历轮原答和导师评估，直接编辑完整学生文档、保存和恢复备份，无需另开源文档页面。
8. 教学页点击“独立窗口”，作答区右上点击 ↗，即可分别打开教学窗口和学生窗口。学生窗口可直接答题，也能查看或编辑完整回答文档；主窗口切换课程或关闭后，独立窗口仍使用原学习文件夹。

可先导入 `demo/StepsToGreat` 体验功能。演示内容为本项目编写，不是真实掌握记录。

## 已实现

- 文件夹导入、资源管理器拖入；顶部按当前任务显示需要读写的文档，移除左侧完整目录树和“全部文件 / 我的学习”筛选。
- 统一浅灰标题栏与页面背景，移除原生“文件 / 编辑 / 视图”菜单；使用圆角卡片、柔和阴影与更宽松的输入区域，保留保存、导入和缩放快捷键。
- 原生 DSH 单列对话面板、独立小窗、置顶、收起与恢复；同一会话的消息、模型选择和草稿在窗口形态之间保持一致。输入区只保留引用、模型和发送操作。
- DSH 小窗采用透明外缘、28px 白色圆角面板和柔和阴影，居中会话标题，提供最小化、置顶与回到主窗口；圆角输入框带细蓝边与焦点光晕，圆形发送/停止按钮。
- 次要灰色文字适当增强字重和对比；按钮悬停、按压、菜单与弹窗使用轻柔动效。聊天内容和正文不会随着每次回复更新重新入场，遵循系统“减少动态效果”设置。
- 从学习档案的当前交接状态读取学科、课程、轮次和真实文档路径；“继续学习”入口及中文用途分类，不推断掌握状态。
- 阅读字号、行距与宽度设置；自动文档目录和双栏滚动同步。
- Markdown/TXT 的 UTF-8 查看编辑；CodeMirror 语法编辑、撤销与查找、实时预览。
- Markdown 表格、只读任务清单、代码围栏、KaTeX 公式、工作区内相对图片与文档链接。
- 黑白灰界面，白色导入按钮；统一细线小图标、清晰的灰色说明文字，代码字迹使用柔和语法颜色。
- 源文档格式工具栏，以及基于 Tiptap 的可视化编辑：标题、粗体、列表、清单、引用、代码块、表格与链接。
- StepsToGreat 的教学引导/学生回答关联；识别问题标题、加粗题号及“本轮题目”中的编号列表；区分普通轮与费曼轮，以最新已发布轮次显示 1–3 题。
- 每次答案提交原文追加；不自动改掌握表、交接状态、最终复评结果或导师评估。
- 作答记录按文档原顺序展示各轮与最终评估，保留未识别段落；完整学生文档可在作答区直接阅读、编辑、处理保存冲突和恢复历史版本。
- 教学文档与学生文档均可打开原生独立窗口；相同文档重复打开会恢复现有窗口。各窗口保留独立草稿，并共享版本校验与写入队列，避免并发覆盖。
- 保存前校验文档版本，防止覆盖外部修改；写入前备份旧版本，临时文件替换。
- 文档与未提交答案自动保存独立本地草稿；切换、重新载入与重启后恢复。关闭窗口前等待草稿保存成功。答案以题目内容识别，题目变化时保留旧草稿供核对。
- 冲突左右对照与手动合并；备份列表、预览、恢复，以及每文档可设置 5–100 个历史版本。
- 外部 Markdown 文档变动提醒、另存文档草稿、最近打开工作区。
- 文档内容无 Node 访问权限；关闭原始 HTML，净化输出；限制文件访问在导入目录内。

## 开源整合

本项目使用开源编辑器与桌面运行时。调查阶段的上游克隆和本地运行时提取文件不进入公开仓库或应用分发。

**Typedown 已下载并检查**。它的 WinUI/WebView2 外壳不适合直接拼进 Electron，旧编辑器依赖还需要单独迁移，因此没有移植 Typedown 的 Muya 编辑器代码。实际整合的是 Electron、CodeMirror 6、Tiptap、markdown-it、chokidar、DOMPurify、KaTeX 与 task-lists；Typedown 为架构和使用体验参考。完整上游克隆不会被打包到软件里。

StepsToGreat 的题目与答案是 Markdown，不是结构化题库。当前没有引入 SurveyJS 等问卷引擎，没有伪造统一 JSON 题目协议。

## 当前边界

- DSH 面板连接已经打开的 DSH 桌面端（已验证 0.2.0-rc.2），共用其原生会话、实时消息和模型目录，不再启动独立 ACP 后台会话。先打开 DSH，再在面板点击“连接”；更多菜单可打开 DSH、选择当前学习文件夹中的同步会话或新建原生会话。DSH 关闭后停止对话，已有历史仍可阅读。
- 模型选项来自当前 DSH 的 `session/modelCatalog`，包含该用户配置的提供方和插件模型；切换使用 DSH 原生选择接口，行为与桌面端相同（包含更新默认模型），保留目标模型支持的推理强度。列出的模型是否能完成请求仍取决于 DSH 内相应账号和额度。
- 桌面连接默认使用 DSH 的本机端口 19387；自定义端口可通过 `STG_DSH_DESKTOP_URL=http://127.0.0.1:端口` 指定，自定义配置目录跟随 `DSH_HOME`。应用只在主进程内读取本机桌面连接授权，不复制模型账号或密钥，授权不会进入打包文件、面板或会话存档。
- 可视化编辑仅用于能够无损转换的常见 Markdown。注释、公式、特殊语法或转换前后内容不等价时，会提示使用源文档编辑。可视化实际修改后会规范化 Markdown 空白与标记样式。
- Mermaid 保留为代码块；PDF、DOCX 等不在本版本解析。
- 答题面板需要已发布题目使用上述可识别格式，且已有配套学生回答。其他格式可直接在源文档里作答。
- 忽略隐藏目录、`.git`、`node_modules`、`vendor`、`release` 与符号链接；过深目录或无权限目录给出提示。工作区内图片可加载，远程图片默认不加载。
- 8 MB 以上文档、非 UTF-8 文件不编辑，避免误保存。支持常见 UTF-8 BOM 与 CRLF，保留未编辑部分。
- 备份位于学习目录的 `.stg-desk/backups/`，保存后按保留数量清理；默认每文档 20 个。恢复前会备份当前版本；有未保存源文档时先保存或另存草稿，再恢复。
- 草稿、最近打开路径和阅读设置保存在系统应用设置目录。输入停顿 250 毫秒后写入草稿，突发断电可能丢失最后尚未写入的输入。草稿恢复不会自动覆盖正式文档。
- 尚未代码签名，Windows 分发会显示未签名程序提示。

## 开发与验证

需要 Node.js 22+，当前环境使用 Node.js 24。

```powershell
npm ci
npm start
npm test
npm run test:desktop
npm run pack
npm run dist
```

`npm run dev` 只启动网页界面预览。开发桌面时先启动它，再在另一个终端设置 `$env:STG_DEV_URL='http://127.0.0.1:5178'` 并执行 `npx electron .`。

桌面验收使用临时演示工作区，不对真实学习目录执行测试写入；本机运行证据不随源码发布。

自动测试覆盖题目与作答记录识别、草稿持久化、文件边界、跨窗口保存冲突、备份恢复和 DSH 桌面连接。桌面测试还验证两个独立文档窗口、主窗口切换文件夹以及主窗口关闭后继续答题。

源码模块：`electron/` 为桌面宿主与受限桥；`lib/workspace.cjs` 为文件访问与保存；`lib/stg.cjs` 为轮次/问题识别与追加；`src/` 为中文界面。

## 独立 DSH 学习插件

DSH 内的学习工作区和学习会话管理已拆为独立项目 [dsh-stg-learning](https://github.com/wildcat430524/dsh-stg-learning)。插件在 DSH 左侧提供“学习”入口、课程关联、置顶、阶段标记和继续原生会话。STG Desk 保留现有阅读编辑界面、侧边对话与小窗，两边通过 DSH 同一个原生会话协作。

两项目可以分别分发与开源，采用各自的 MIT 许可证。插件通过 DSH 的插件管理安装或卸载，不包含 DSH 宿主源码。插件的个人整理标记不替代真实掌握评估，也不自动写入学习文档。
