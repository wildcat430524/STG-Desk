# v0.3.10 · 一键保存作答与现有修改

现在点击「保存本轮作答」、底部「保存」或按 `Ctrl+S`，都会直接保存现有修改。答题区的输入写入学生回答文档，回答全文和当前教学文档中的编辑一并保存，不再要求先保存另一份文件。

- 普通布局和专注作答使用相同的保存逻辑；已填写但当前未显示的题目也会保存。
- 「完整文档」预览包含本轮尚未保存的答案。
- 去掉「另存草稿」入口、草稿状态文案和手动合并弹窗；意外关闭后的输入恢复在后台完成。
- 修复旧编辑记录仅因 Markdown 转义符不同就被恢复的问题，避免过期教学内容遮住磁盘上的新版。
- 保存时自动保留可合并的外部修改；重叠修改使用当前编辑内容，覆盖前的磁盘内容自动备份。
- 若题目本身已更换，保留输入并提示查看新题，避免把旧题答案写入另一道题。
- 连续点击保存不会重复追加已经保存的答案；已有原答、导师评估和历史版本继续保留。
- 保存后继续输入的内容仍保留为待保存修改。保存本身不再自动打开 DSH 或准备评估请求。

验证：170 项单元测试通过；完整桌面冒烟验收、作答布局验收、一键保存专项验收和打包后的桌面程序验收通过，完整桌面验收无渲染进程报错。

Windows x64：下载 `STG-Desk-0.3.10-Windows.exe`。可选的 `STG-Desk-0.3.10-EditorShowcase.zip` 包含复杂内容演示，解压后导入 `EditorShowcase` 根目录。`SHA256SUMS.txt` 提供附件校验值。

## English

Save this round, the bottom Save button, and `Ctrl+S` now save current edits directly. Question inputs are written to the student answer document together with pending full-answer and lesson edits, without a prerequisite save.

- Normal and focused layouts share the same save behavior, including answers to hidden questions.
- The full-document preview includes pending question inputs.
- The separate draft export, draft status text, and manual merge dialogs are removed. Input recovery remains automatic in the background.
- Serializer-only Markdown escaping no longer restores an outdated lesson over the latest file.
- Independent external edits are carried forward when possible. Overlapping changes use the current edit, with the disk version backed up first.
- Changed questions retain pending input and require review, so an old answer is not attached to a different question.
- Repeated saves do not duplicate already-saved answers. Existing answers, tutor feedback, and history remain available.
- Input entered while saving remains pending. Saving no longer opens DSH or prepares a review request automatically.

All 170 unit tests passed, along with full desktop smoke checks, answer-layout checks, focused save acceptance, and packaged desktop acceptance. Full desktop checks reported no renderer errors.

Download `STG-Desk-0.3.10-Windows.exe` for Windows x64. The optional `STG-Desk-0.3.10-EditorShowcase.zip` contains the complex-content demo. Checksums are provided in `SHA256SUMS.txt`.
