# v0.3.11 · 回答区与文档同步

- 保存后，「你的回答」继续显示刚保存的内容，切题、重启后也能从回答文档读回。
- 再次编辑保存会更新当前答案；清空并保存也会同步到文档，不会恢复旧答案或重复追加当前作答。
- 移除「查看本题已保存记录」。全文编辑和外部文档更新可同步到答题区；尚未保存的输入保留。
- Ctrl+S 保存时保留输入焦点和光标位置。已有历史原答、导师反馈与保存前备份保留。

177 项单元测试、一键保存专项验收、作答布局验收和完整桌面冒烟检查通过。

## English

Saved answers remain editable in the answer inputs and reload from the document. Saving edits updates the current answer; clearing and saving clears it without duplicating answers or reviving an older record. Full-document and external edits synchronize with the inputs. The saved-record disclosure is removed, and Ctrl+S preserves input focus and cursor position. Existing history, tutor feedback, and backups remain available.

All 177 unit tests, save acceptance, answer-layout acceptance, and full desktop smoke checks passed.
