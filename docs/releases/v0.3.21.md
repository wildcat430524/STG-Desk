# STG Desk 0.3.21

- **DSH 多版本适配**：完整适配 DeepSeek Harness 0.1.x / 0.2.0 / 0.2.1 / 0.2.2+。支持自动发现 DSH 0.2.1+ 随机本地端口（`--port 0`）与托盘驻留进程，同时兼容 DSH 0.2.0 默认端口（`19387`）与 `dsh web` 本地无 Cookie 会话，并扩展 Windows 注册表（HKCU / HKLM / WOW6432Node）与 0.2.2+ 运行时目录自动探测。
- **DSH 协议与连接可靠性**：适配 0.2.2+ 模型角标（`badge`）、`session/projections` 空值与迁移状态容错，复用非空历史会话时不再额外创建空白会话；断线、重启或 `401`/`503` 时自动重新探测端口并刷新授权 Cookie，连接冷启动改用退避重试，WebSocket 在线期间自动跳过进程轮询。
- **对话上下文去重与压缩适配**：同一会话连续多轮发送时按文档内容哈希增量注入已保存的教学引导、学生回答、学习档案与规则，控制上下文长度并兼容新旧会话压缩事件（`surfaceOp.op` / `surfaceOp.kind`）。
- **原子持久化与整体优化**：统一 `settings.json` 串行原子写入与 Windows 文件占用重试替换机制（覆盖配置、文档与草稿保存）；优化顶栏紧凑语言切换器与中英文状态文案映射，修复 EN→ZH 切换时标题/状态残留、DSH 发送按钮忙态判断与并发文件监听合并问题，并将模型分组计数优化为线性时间。

验证：215 项单元测试通过；Windows Electron 冒烟验收、中英文界面验收、模型选择验收与 UI 系统验收全部通过，已在本地 DeepSeek Harness 0.2.2-rc.5 实机验证安装探测。

下载 `STG-Desk-0.3.21-Windows.exe`，双击运行。Windows 便携版无需单独安装 Node.js。
