# v0.3.6 · Markdown 编辑体验升级

本次更新集中在 Markdown 文档区域：更舒适的阅读配色、更清楚的内容层级，以及可以直接操作的代码与公式。

## 编辑器

- 浅色纸面、白底细边框代码块、标题层级提示、轻量引用线；同时完善深色文档样式。
- 复用 highlight.js 的 Atom One Light / Dark 主题，支持 Java、Python、JavaScript、TypeScript、SQL 等 17 种语法语言及纯文本。
- 代码块可选择语言并复制当前代码；高亮与工具条不写入 Markdown 内容。
- 行内与块级数学公式使用 KaTeX 渲染。通过公式按钮插入、实时预览，双击已有公式修改。
- 修复公式与行内代码混排，代码中的美元符号保留为代码。
- 统一编辑器 SVG 工具图标，改善表格、任务清单与窄窗口阅读。

应用其他区域的颜色保持原样。未修改区块继续保留原 Markdown，包括 CRLF、BOM、元数据与引用定义；保留撤销、组合输入和外部修改保护。

## 复杂内容演示

下载并解压 `STG-Desk-0.3.6-EditorShowcase.zip`，在应用中「导入学习文件夹」选择 `EditorShowcase` 根目录。

演示包含 Java 17+ Stream / CompletableFuture、Python 梯度下降、TypeScript 异步重试、SQL 窗口函数、矩阵与梯度公式，以及表格、嵌套清单和任务框。演示记录仅用于查看界面效果。

## English

This release improves Markdown reading and editing with neutral light/dark document styles, scoped Atom One syntax themes, selectable code languages and copy actions, live KaTeX formula insertion/editing, and consistent SVG controls. Colors outside the Markdown editor remain unchanged.

The separate EditorShowcase ZIP contains complex Java 17+, Python, TypeScript and SQL examples, matrices, gradients, tables and nested checklists. Extract it and import the `EditorShowcase` root folder. All 154 unit tests and the Windows packaged desktop smoke test passed. The Python example was executed; the Java 17+ example was reviewed but not compiled on the local Java 11 environment.
