STG Desk 0.3.17

- 模型菜单改为与工作台一致的浮层：按服务商分组，支持搜索模型和服务商，独立显示价格标记与当前选中状态。
- 支持方向键选择、Enter 确认、Esc 关闭及焦点返回；中文输入法选词时不会误切换模型。切换失败保留原模型，回复生成期间禁止切换。
- 模型面板自动适应侧栏、独立小窗、窗口缩放与明暗主题。
- 正式包含上一轮界面优化：统一控件与对比度，可调整教学 / 作答 / DSH 面板宽度，窄区域切换教学和作答，改进对话阅读位置、复制反馈及弹层键盘操作。

验证：185 项自动测试通过；原生 Electron 回归覆盖模型搜索与切换、失败恢复、中文输入法、键盘操作、明暗主题、125% 缩放和独立小窗，并回归作答保存、轮次切换与工作台面板交互。
