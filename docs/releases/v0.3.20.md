# STG Desk 0.3.20

- 新增简体中文与英文界面切换，默认中文；欢迎页、编辑器、弹窗、进度页和 DSH 面板即时更新。
- 语言偏好会在重启后恢复，并在主窗口、独立文档窗口和 DSH 小窗之间同步。切换时保留草稿、选区、当前文档和会话；课程正文、文件名及用户内容保持原文。
- 顶栏的继续学习、导入文件夹、打开 DSH 与语言切换统一高度、字号和间距，窄窗口整组换行。
- 修复启动时语言偏好可能被默认值覆盖，以及快速切换时偏好可能保存为旧值的问题；清理已关闭编辑器的语言监听。

验证：206 项自动测试通过；Windows Electron 界面验收覆盖语言切换、重启恢复、跨窗口同步、保存、草稿恢复和窄窗口布局。

下载 `STG-Desk-0.3.20-Windows.exe`，双击运行。Windows 便携版无需单独安装 Node.js。
