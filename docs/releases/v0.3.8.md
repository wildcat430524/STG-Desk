# v0.3.8 · 轮次识别与题面截断修复

本次更新修复了学生回答文档中「被注释预留的后续轮次」被误识别为当前正式轮次与历史记录的问题，并修正按题作答的题面截断。真实课件仍显示第二轮的问题 3、4，注释里预留的第三轮不再参与作答。学习文档历史、备份与保存保护保持原有实现。

## 轮次识别

- 学生回答文档常用 HTML 注释预留后续轮次，例如 `<!-- 第三轮 · 问题 5：综合练习 -->`。
- 此前题目解析按普通 Markdown 处理这些行，注释里的 `## 第三轮 · 问题 5` 会被当成真实标题。
- 由此产生的错误行为是：作答区跳到尚未发布的第三轮，而该「题目」的题面只剩注释结束标记 `-->`，作答记录里也多出一个以注释内标题为名的第三轮区块。
- 现在解析先按 HTML 块处理文档，注释整体作为不可见内容：只有已发布轮次参与轮次与题目识别。
- 真实课件的当前轮次为第二轮、含问题 3 与问题 4，界面正确显示第二轮 2 题；注释中预留的第三轮不再出现。
- 注释原文与其在文档中的位置逐字保留，保存不会改写或删除预留内容。

## 题面截断

- 作答输入占位标记 `**你的代码：**` 现在与 `**你的回答：**` 一样结束题面。
- 此前代码类题目只会在 `**你的回答：**` 处截断，`**你的代码：**` 之后的模板代码块会被并入题面。
- 现在题面在占位标记处结束，模板与预留内容不再混入题目。
- 题面本身包含 fenced 代码块时仍按原有规则处理，代码围栏内的伪标题不受影响。

## 历史与保存保护

作答记录（历轮原答、导师评估与最终复评）、历史版本备份与恢复、写入前版本校验与备份、外部修改提醒均保持原有实现，保存格式与备份策略未改动。章节轮次与课程状态也会忽略注释中的预留内容；掌握表和课程路线里的注释占位行不再计入进度统计。

## English

This release fixes future rounds reserved inside HTML comments being mistaken for the current published round and for history, and corrects where the prompt of a question ends. Real courseware still shows round two with questions 3 and 4, and a round three reserved in a comment no longer takes part in answering. Document history, backups, and save protection are unchanged.

- Answer documents often reserve later rounds in HTML comments, for example `<!-- 第三轮 · 问题 5：综合练习 -->`.
- The question parser used to treat those lines as ordinary Markdown, so `## 第三轮 · 问题 5` inside the comment was read as a real heading.
- The visible symptom was that the answer workspace jumped to an unpublished round three, that question's prompt was left as the lone comment terminator `-->`, and the answer records gained a round-three block named after the heading inside the comment.
- The parser now resolves HTML blocks first, so a comment is opaque: only published rounds take part in round and question detection.
- The real courseware's current round is round two with questions 3 and 4, and the interface now shows those 2 questions; the reserved round three no longer appears.
- Comment text and its offsets are preserved byte for byte, and saving never rewrites or deletes reserved content.

The input placeholder `**你的代码：**` now ends the prompt, exactly like `**你的回答：**`.

- Previously only `**你的回答：**` stopped the prompt, so a template code block after `**你的代码：**` was folded into the question.
- The prompt now ends at the placeholder, and template or reserved content no longer leaks into a question.
- Fenced code inside a prompt keeps the existing rules, and pseudo-headings inside code fences are still ignored.

Answer records (previous answers, tutor evaluations, and final reassessments), history backups and restoration, version checks and backups before writes, and external-change alerts keep their existing implementation; the save format and backup policy are unchanged. Chapter rounds and course status also ignore commented placeholders, and commented mastery tables or route units no longer contribute to progress counts.

All 162 unit tests passed, including commented rounds, status, mastery tables and route units, code prompt boundaries, and question-based saving. The source build passed 25 desktop smoke checks with no renderer errors, including a commented future-round regression in answer cards and history. Packaged modules match the accepted source; a read-only check of real courseware confirms round two with questions 3 and 4 and chapter progress at round two, without changing learning files.
