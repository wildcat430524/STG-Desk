# v0.3.7 · 界面字号与可读性优化

本次更新统一调整整个应用的界面字号：信息文字不再过小，常用按钮和输入区更好读，文档表格跟随正文字号缩放。界面配色、学习数据与 DSH 账号模型保持不变。

## 字号与可读性

- 统一了工具栏、状态提示、作答区和 DSH 的字号层级。
- 元信息与辅助说明文字由 9–11px 提升到 12px。
- 常用按钮由 10–12px 提升到 13–14px，底部文档操作按钮与作答页签为 13px，阅读设置与 DSH 标题为 14px。
- 作答文本框与 DSH 输入框使用 15px，文档栏标题为 16px，作答说明为 13px。
- 欢迎页、进度辅助、阅读设置、历史版本、公式与代码工具、DSH 面板与小窗使用同一字号梯度。
- 文档表格此前固定为 12px，现改为继承正文；实测正文 16px 时表格为 16px，正文 21px 时表格为 21px。
- 文档正文字号仍由「阅读设置」控制，默认 16px，可在 13–24px 之间调整；各级标题与正文的比例关系保持不变。
- 仅有的布局微调是收紧标题区按钮的内边距，并允许作答页签在窄窗口下换行。

## 原有设置与保存保护

阅读设置、夜间主题与专注模式行为不变，导入目录、草稿、版本校验、写入前备份、外部修改提醒与历史恢复保持原有实现，未保存的输入仍由自动草稿恢复。

## English

This release raises the interface type scale across the whole app: small metadata is no longer hard to read, common buttons and inputs are more legible, and document tables now scale with the body text. Interface colours, learning data, and the DSH account model are unchanged.

- Toolbars, status text, the answer workspace, and DSH use a consistent type scale.
- Metadata and helper text moved from 9–11px to 12px.
- Common buttons moved from 10–12px to 13–14px; document action buttons and answer tabs are 13px, and reading settings and DSH headings are 14px.
- The answer textarea and the DSH input use 15px, the document heading is 16px, and answer help text is 13px.
- The welcome screen, progress helpers, reading settings, version history, formula and code tools, and the DSH panel and floating window share the same scale.
- Document tables previously used a fixed 12px and now inherit the body text: measured 16px at a 16px body size and 21px at 21px.
- Body text is still controlled by 「阅读设置」 (Reading settings) — 16px by default, adjustable from 13 to 24px — and heading-to-body ratios are unchanged.
- The only layout tweaks are tighter header-button padding and answer tabs that wrap in narrow windows.

Reading settings, the night theme, and focus mode behave as before. Import, drafts, version checks, backups before writes, external-change alerts, and history restoration are unchanged, and unsaved input is still recovered from automatic drafts. All 154 unit tests passed, along with 13 real Electron typography and layout states (welcome, lesson, docked DSH, 1050×720 narrow dock, night, reduced motion, a roughly 400×600 floating DSH window, answer records and full document, reading settings, 21px body text, and the 550px detached teaching and answer windows). The full desktop smoke run passed 24 evidence items with no renderer errors, and the shipped CSS/JS build is byte-identical to the accepted version. No state showed horizontal container overflow, and the answer tabs and footer buttons remained fully clickable.

The Windows portable EXE also passed all 24 desktop smoke checks with an isolated profile. Download `STG-Desk-0.3.7-Windows.exe`; `SHA256SUMS.txt` provides SHA-256 checksums. The optional `STG-Desk-0.3.7-EditorShowcase.zip` contains complex-content examples; extract it and import the `EditorShowcase` root folder.
