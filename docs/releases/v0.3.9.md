# v0.3.9 · 作答工作区布局更新

本次更新重排了教学旁的作答工作区：顶部与底部固定区更窄，正文可用高度明显增加，当前轮改为一次一题，题干不再单独滚动，并新增「专注作答」。按题追加保存、写入前备份、版本校验、完整文档编辑与独立学生窗口都保持原有实现，保存格式与学习文档内容未改动。

## 作答栏与可用高度

- 作答栏默认宽 420px；DSH 停靠打开时为 360px，更窄的窗口下为 330px。
- 顶部标题收成两行、约 76px，保存区收成单行、约 62px；实测 1460×960 下中间可用高度由 306.5px 增至 431px，约增加 41%。
- 窄栏内的状态文字可以换行，保存按钮仍在同一行，互不重叠。

## 一题一屏与逐题切换

- 当前轮的题目按题号导航逐题显示，切题不会丢失已输入的内容；草稿按题保留。
- 已填写的题在题号旁显示 `✓`，没有填写的题不显示。
- 切到「作答记录」或「完整文档」页签时题号导航隐藏，切回「本轮作答」后仍停留在原题。
- 提交时整轮已填写的答案一起追加到学生文档，隐藏题的答案同样会被提交。

## 题干展开与收起

- 长题干默认折叠，短题干默认展开；展开与收起状态由题干长度决定，不是记住上次选择。
- 题干不再有独立滚动区域，题干与回答随整列统一滚动；代码块仍可横向滚动。

## 文本框高度

- 文本框最小高度 240px，按作答内容区的实际尺寸自适应，普通布局上限 380px，专注作答上限 560px。
- 文本框仍可手动纵向拖拽调整。

## 专注作答与键盘

- 点「专注作答」隐藏教学文档、上方工作区头部与文档操作按钮，把答题列居中，最大宽 900px；按钮文字改为「返回对照」。
- 按 `Esc` 返回普通布局；此时旧的窄窗口隐藏规则恢复原样，作答栏重新按原有条件显示或隐藏。
- 专注作答中按 `Ctrl+S` 保存整轮答案（完整文档页则保存回答文档）。
- 普通布局下的 `Ctrl+S` 仍保持原有行为：保存当前文档，完整回答文档处于编辑状态时保存回答文档。
- 专注作答在 1050×760 窄窗口下不出现横向溢出，输入框与保存按钮完整可见；夜间主题、系统「减少动态效果」和键盘焦点样式均适配。

## 保持不变的实现

按题追加保存、自动草稿、写入前备份与备份保留数量、版本校验与外部修改提醒、历史版本恢复、完整回答文档编辑，以及独立教学/回答窗口都沿用原有实现；作答栏仍是可选的评估入口，提交不会自动修改掌握表或交接状态。

## English

This release rearranges the answer workspace beside the lesson: less fixed chrome at the top and bottom, a noticeably taller content area, one question at a time in the current round, prompts that no longer scroll on their own, and a new focused answering mode. Appending answers by question, backups before writes, version checks, full-document editing, and detached student windows keep their existing implementation; the save format and the learning documents are unchanged.

- The answer column is 420px wide by default, 360px while the DSH panel is docked, and 330px in narrower windows.
- The heading is two lines at about 76px and the save footer is a single row at about 62px; measured at 1460×960, the usable content height grows from 306.5px to 431px, about 41% more.
- In a narrow column, status text can wrap while the save button stays beside it without overlapping.

- The current round shows one question at a time with a question-number navigation strip; switching questions never loses typed text, and drafts are kept per question.
- Questions that have been filled in show `✓` next to their number; empty ones do not.
- The strip is hidden on the answer-records and full-document tabs and returns to the same question when the current-round tab comes back.
- Submitting appends every filled-in answer of the round, including answers to questions that are not currently on screen.

- Long prompts start folded and short prompts start expanded, decided by prompt length rather than by remembering the last choice.
- Prompts and answers scroll together instead of using a separate prompt scroll area; code blocks can still scroll horizontally.

- The textarea is at least 240px tall, follows the real size of the answer content area, caps at 380px in the normal layout and 560px in focused mode, and can still be resized vertically by hand.

- 「专注作答」 (Focused answering) hides the teaching document, the workspace header, and the document actions, and centres the answer column at up to 900px; the button then reads 「返回对照」.
- Press `Esc` to return; the previous narrow-window hiding rules apply again and the answer column shows or hides exactly as before.
- In focused answering, `Ctrl+S` saves the whole round (or the answer document on the full-document tab).
- In the normal layout `Ctrl+S` keeps its existing behaviour: it saves the current document, or the answer document while that is being edited.
- Focused answering shows no horizontal overflow at a narrow 1050×760 window and keeps the textarea and save button fully visible; the dark theme, the system reduced-motion setting, and keyboard focus rings are all covered.

Appending answers by question, automatic drafts, backups before writes and their retention count, version checks and external-change alerts, history restoration, full answer-document editing, and the detached teaching and answer windows are unchanged. The answer workspace remains an optional evaluation entry and never updates mastery tables or handoff status by itself.

All 162 unit tests passed. Answer UI acceptance covers long code prompts, question switching, restoring both drafts after a reload, the three tabs, focused answering at 1050×760, the dark theme, and saving hidden answers while retaining final-reassessment text. The actual Windows portable executable passed 25 desktop smoke checks with no renderer errors. Packaged business modules, page assets, licenses, icons, and bundled demos match the accepted source. Both READMEs include updated instructions, the current workspace screenshot, and a new answer-area preview.
